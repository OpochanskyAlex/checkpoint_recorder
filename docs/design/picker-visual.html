Inline keyboard (up to 4)Metrics ordered by most recently logged. Pressing a button resolves the metric and continues the command.
Show all fitsAppears when >4 fuzzy matches exist. Expands the keyboard in-place to show every match.
Create buttonOnly shown in logging flow when zero metrics match. Starts new-metric creation flow (periodicity prompt).
Last 3 valuesShown immediately after metric selection in logging flow, before asking for new value.
State: PendingMetricPickerActive from keyboard display until selection or /cancel. At most one per user (BR13).
/cancel (FR31)Clears PendingMetricPicker or PendingPickerValue state at any point, returns to Idle.
